What is GVHMR?

GVHMR (Gravity-View Human Motion Recovery) is a state-of-the-art system that recovers 3D human motion from video in world-grounded coordinates. Unlike traditional methods that estimate pose in camera space, GVHMR provides world-coordinate results using gravity-view coordinates.

How to Use

  1. Upload Video: Select a video file (MP4, AVI, MOV, or MKV format, max 500MB)
  2. Configure Settings: Choose whether your camera is static or moving
  3. Process: Click "Process Video" and wait for the analysis to complete
  4. Download Results: View and download the processed motion data

Camera Settings

  • Static Camera: Use this option if the camera was stationary during recording. This skips visual odometry for faster processing.
  • Moving Camera: Use this option if the camera was moving. GVHMR will estimate camera motion using SimpleVO.

Output Format

GVHMR produces:

  • 3D human pose and shape parameters (SMPL format)
  • World-grounded motion trajectories
  • Visualization files (if enabled)

Technical Details

  • Paper: SIGGRAPH Asia 2024
  • Repository: github.com/zju3dv/GVHMR
  • Requirements: GPU with CUDA support (NVIDIA recommended)
  • Processing Time: Varies based on video length and resolution (typically 5-10 minutes for a 30-second clip)
